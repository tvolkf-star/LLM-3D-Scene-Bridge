## Architecture

No autonomous agent framework, specialized 3D model, text-to-3D generator, or custom modeling environment. Google Drive is a third-party synchronized transport layer. A compact Python/pymxs bridge executes operations inside a locally running Autodesk 3ds Max and returns observable results.

```text
Task → ChatGPT → Google Drive → local sync
                                  ↓
                          Python/pymxs bridge
                                  ↓
                           3ds Max 2024
                                  ↓
                       native editable geometry
                                  ↓
                     result + scene + viewport
                                  ↓
                         Google Drive → ChatGPT
                                       ↺
```

**IMPORTANT: This is not 3D asset or image generation. It is direct modeling inside Autodesk 3ds Max.** The language model operates the application's native tools to construct actual scene geometry.

**Modeling operations are generated by the general-purpose LLM and executed through native 3ds Max tools. Geometry remains native and editable inside 3ds Max.** No manual code copy-paste is required during the connected modeling loop.

## Scene as executable text

A further finding emerged during the experiments: **an LLM can express a 3D scene as an executable text script**, which reproduces the scene's native geometry on another computer running Autodesk 3ds Max. This was tested successfully with **3ds Max 2024**: the geometry was reproduced exactly.

For the tested scene of **four chairs and one table, the complete reconstruction script is only 14 KB**. This is an **ultra-compact textual representation of the scene**, not a simplified or reduced version of its geometry. Executing the script reconstructs the native, editable scene in 3ds Max.

Because the representation is text, other language models can read it, examine the modeling logic, and modify the scene by editing the script, without having to parse a binary `.max` file. How effectively a particular model performs these tasks depends on its capabilities.

The result is an **ultra-compact, LLM-readable way to transfer, reconstruct, and edit scene geometry**. Exact reproduction has been verified in **Autodesk 3ds Max 2024** on another computer. **Tests with other versions of 3ds Max or other 3D applications have not been conducted.**

**Executable scene examples:** [MARGARITA, full reconstruction script (14,552 bytes)](examples/margarita/MARGARITA_v4_FULL_SOURCE.py) · [MARGARITA, compact script](examples/margarita/MARGARITA_v4_12KB.py) · [Stool](examples/stools/GPT_FROSTA_Instant_000027.py) · [Pergola](examples/pergola/MAF035_Pergola.py). These are readable Python/pymxs source files; open them to inspect the modeling operations or run them in a suitable 3ds Max environment. The full MARGARITA source notes that its oversized shell reconstruction still requires visual comparison.


**To reproduce a scene:** open Autodesk 3ds Max 2024, select **Scripting → Run Script**, choose the downloaded scene `.py` file, and run it. Save your current scene first: some examples delete or rebuild objects.

## Installation

1. [Download the complete ZIP](https://github.com/tvolkf-star/LLM-3D-Scene-Bridge/releases/download/v0.6.1-portable/TASY_MaxBridge_v0.6.1_PORTABLE_COMPLETE.zip) and extract it to a writable local folder.
2. Open **Autodesk 3ds Max 2024 → Scripting → Run Script** and run `TASY_MaxBridge_061_PORTABLE.py`.
3. Synchronize the working folder using Google Drive for desktop and verify two-way file synchronization.
4. Give ChatGPT or another capable large language model access to the corresponding Google Drive folder and project documentation.
5. Give the model the MaxBridge documentation and working examples. The bridge is ready for the modeling task; `ping` is a diagnostic action, not a required startup step.

[Detailed installation guide (Russian)](docs/INSTALL_RU.md) · [File protocol](protocol/FILES.md).

**Security:** `execute_python` executes arbitrary Python with the privileges of the 3ds Max process. Use only trusted command sources and save existing scenes before experiments.

## Research and source files

[English research](RESEARCH_EN.md) · [Russian research](RESEARCH_RU.md) · [Portable bridge](TASY_MaxBridge_061_PORTABLE.py) · [Examples](examples/) · [Documentation](docs/).

This research does not claim to be the first LLM-to-3ds-Max integration. Nevertheless, it produced noteworthy practical results using an approximately **8 KB Python/pymxs bridge**, without an autonomous agent framework, specialized 3D model, or additional orchestration libraries. The experiments were conducted with **GPT-5.6 Sol in Instant mode** through the standard ChatGPT interface, without a dedicated API workflow or separate API token budget.

**Important:** The bridge provides access to Autodesk 3ds Max. It does **not** teach a language model how to model. Effective modeling requires geometric reasoning, construction methods, and feedback. Capable language models can adopt existing professional modeling techniques through examples and guided practice.

The repository includes executable examples of native 3ds Max geometry to help a model become familiar with the environment and accelerate this learning process.
