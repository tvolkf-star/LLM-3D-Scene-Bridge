# MaxBridge: урок 2. Чистая геометрия из сплайна

**Автор методики и примеров:** Tasy Volkova  
**Проект:** LLM-3D-Scene-Bridge  
**Назначение:** рабочая памятка для языковой модели, управляющей 3ds Max через MaxBridge.

## Метод по скриншотам автора

1. **Набросок объёма.** Простыми Box наметить габариты, взаимное положение опоры, сиденья и навеса. Это временные направляющие, не итоговая модель.
2. **Набросок линии.** Построить единый профильный сплайн, который выражает конструктивную идею: вертикаль, переход, горизонтальная часть, изгиб и окончание.
3. **Придать сплайну сечение.** Включить Renderable spline / прямоугольный профиль и увидеть фактическую толщину элемента.
4. **Довести вершины и касательные уже с толщиной.** Проверить изгибы, сопряжения, расстояния, отсутствие пересечений, изломов и некрасивых заломов. Геометрию корректировать по видимому объёму, а не только по осевой линии.
5. **Проверить одиночный готовый профиль.** Только после этого тиражировать через Snapshot/анимацию или создавать набор параметрических сечений.
6. **Удалить или скрыть вспомогательные Box и траектории** после проверки результата; не путать вспомогательные объекты с итоговой конструкцией.

## Для языковой модели, работающей через MaxBridge

- Не пытайся сразу строить сложную форму десятками примитивов. Сначала создай и проверь **один чистый сплайн-профиль**.
- Контрольные этапы: набросок объёма → осевой сплайн → сплайн с толщиной → правка сопряжений → одиночная готовая деталь → тиражирование.
- Не принимай геометрию за качественную только потому, что скрипт отработал без ошибки: проверяй `viewport.png`, `scene.json`, особенно узлы изгибов и торцы.
- Исходный метод Tasy Volkova допускает использование временных Box как пространственных ориентиров, но не требует включать их в финальную модель.
- Сохраняй отдельные результаты экспериментов; не сбрасывай и не перезаписывай чужую рабочую сцену без явного согласия.

## Иллюстрации, предоставленные автором

1. «1 набросок формы» — два Box, намечающие посадку и габариты.
2. «2 набросок линии» — профильный сплайн на фоне вспомогательных Box.
3. «3 меняем точки уже с толщинками» — доводка кривой при видимом прямоугольном сечении.
4. «3 результат — идеальная модель, вспомогашки можно убрать» — очищенная одиночная деталь.
5. «2026-09-28_07-51-39» — пример развитой ламельной перголы, построенной на принципе повторяемого профиля.
