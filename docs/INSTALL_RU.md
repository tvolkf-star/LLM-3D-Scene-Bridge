# TASY MaxBridge 0.6.1 PORTABLE


## Быстрый запуск


1. Скачайте полный комплект и распакуйте его в отдельную папку.
2. В Autodesk 3ds Max 2024 выберите **Scripting → Run Script** и запустите `TASY_MaxBridge_061_PORTABLE.py`.
3. Мост сам создаст рядом с собой необходимые служебные файлы и папку `library/`.
4. Настройте синхронизацию этой папки через Google Drive.
5. Предоставьте ChatGPT доступ к синхронизированной папке, передайте ему документацию MaxBridge и попросите изучить рабочие примеры.


**Готово. Можно ставить задачу и моделировать.**


Не требуется вручную создавать `command.json`, выполнять обязательный `ping` или строить тестовый чайник перед началом работы. Это диагностические действия, а не штатная процедура запуска.


## Что делает мост


ChatGPT формирует команды Python/pymxs. MaxBridge выполняет их внутри работающего Autodesk 3ds Max 2024 и возвращает результат выполнения, состояние сцены и, когда захват доступен, изображение viewport.


Мост не содержит собственной логики моделирования. Он обеспечивает двусторонний обмен между языковой моделью и 3ds Max.


Основные рабочие файлы:


- `command.json` — команда для Max;
- `result.json` — результат выполнения;
- `scene.json` — сведения о текущей сцене;
- `viewport.png` — изображение активного viewport;
- `bridge_status.json` — состояние моста;
- `bridge_state.json` — ID последней принятой команды;
- `library/` — библиотека исполняемых примеров.


## Для ChatGPT


Перед началом работы изучите документацию и проверенные примеры проекта. Не начинайте заново исследовать уже работающий мост и не запускайте диагностические тесты без признаков неисправности.


При работе:


- используйте новый ID для каждой команды;
- после отправки команды сверяйте `result.json.command_id` с отправленным ID;
- анализируйте не только `status`, но и `scene.json` и `viewport.png`;
- не считайте успешное выполнение Python доказательством правильности геометрии;
- сохраняйте в библиотеку только проверенные удачные методы и результаты;
- при наличии рабочего контекста продолжайте текущую задачу, а не возвращайтесь к тестовому `ping` или примитивам.


Главный универсальный способ управления Max: `execute_python` через нативный `pymxs`.


## Если что-то не работает


### После запуска не появились служебные файлы


Убедитесь, что мост запущен именно через **Scripting → Run Script** и что папка со скриптом доступна для записи. Проверьте сообщения Python Listener и путь `ROOT`.


### ChatGPT не видит изменения


Проверьте синхронизацию Google Drive в обе стороны. MaxBridge сам не управляет Google Drive и не использует Google Drive API.


### Команда не выполняется


Проверьте:
- находится ли `command.json` в рабочей папке;
- корректен ли JSON;
- используется ли новый ID;
- содержит ли `execute_python` поле `code`.


### Команда выполнилась, но геометрия неправильная


Это не неисправность моста. Проверьте viewport и состояние сцены, исправьте метод моделирования и выполните следующую итерацию.


### Не сохранился viewport


`viewport_saved: false` не означает, что команда моделирования не выполнилась. Проверьте `result.json` и сцену отдельно.


### Проблемы записи в синхронизированную папку


Сначала проверьте права доступа и реальную двустороннюю синхронизацию. Не переносите рабочую папку и не меняйте код моста только потому, что один способ записи через подключение Google Drive дал ошибку.


Если конкретное подключение ChatGPT читает папку, но не может обновлять рабочие файлы, используйте доступные операции записи для существующих файлов и проверяйте результат по соответствующему `command_id`. Детали конкретного коннектора могут меняться и не являются частью протокола MaxBridge.


## Безопасность


`execute_python` выполняет произвольный Python-код с правами процесса 3ds Max. Используйте только доверенный источник команд, не открывайте рабочую папку для публичной записи и сохраняйте важные сцены перед запуском незнакомого кода.


Не запускайте два экземпляра MaxBridge, работающих с одним и тем же `command.json`.


## Проверенная среда


Проект проверялся с Autodesk 3ds Max 2024 и Python/pymxs. Другие версии Autodesk 3ds Max отдельно не проверялись.
