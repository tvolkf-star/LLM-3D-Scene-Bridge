# Моделирование анимацией: Path Constraint → Auto Key → Snapshot

**Автор метода и учебного примера:** Tasy Volkova  
**Среда:** Autodesk 3ds Max 2024  
**Проект:** LLM-3D-Scene-Bridge / TASY MaxBridge  
**Источник:** учебная последовательность из восьми скриншотов, предоставленных автором 11.10.2026.

## Суть метода

Использовать временную шкалу как дополнительную координату моделирования. Исходный сплайн движется по заданной траектории, одновременно его вершины изменяют положение на ключевых кадрах. 3ds Max интерполирует промежуточные состояния. **Snapshot в режиме Range / Mesh** материализует выбранные состояния анимации в отдельные сеточные объекты. Получается пространственная последовательность различных профилей, из которой можно строить кресла, скамейки, стены, перголы и скульптурные формы.

**Это не анимация готовой перголы. Это использование анимации для генерации статической геометрии.**

## Авторский урок, восемь шагов

1. Нарисовать исходную линию (профиль). В примере это сплайн с несколькими вершинами.
2. Нарисовать вторую линию, путь. На скриншотах это окружность, но путь может быть произвольным сплайном.
3. Назначить исходному сплайну **Animation → Constraints → Path Constraint**, указать второй сплайн как путь.
4. Настроить **Follow** при необходимости, затем перейти на начало временного диапазона.
5. Включить **Auto Key**. На выбранных участках timeline смещать вершины исходного сплайна, задавая ключевые состояния его формы. В учебном примере диапазон 0–320 кадров.
6. Выбрать **Tools → Snapshot**.
7. В окне Snapshot выбрать **Range**, диапазон **From 0 / To 320**, **Copies 200**, **Clone Method: Mesh**. Числа относятся к примеру, а не к обязательным настройкам. Режим **Mesh** принципиален для этого урока.
8. Получить последовательность пространственных сеточных сечений. В зависимости от формы профиля, траектории и ключей можно создавать архитектурные и предметные конструкции.

## Два независимых источника изменения

- **Path Constraint:** задаёт положение и, при включённом Follow, ориентацию профиля вдоль пути.
- **Анимация вершин:** изменяет саму форму профиля по времени.

Snapshot берёт состояния **после оценки обеих анимаций**. Если анимировать только движение по пути, получится последовательность одинаковых профилей. Если анимировать только вершины без движения, профили будут наложены друг на друга.

## Для языковой модели, работающей через MaxBridge

1. Не заменяй описанный метод молча математическим генератором сечений: это другой подход, даже если результат внешне похож.
2. Для буквального воспроизведения создай два сплайна, Path Constraint, ключи вершин, затем Snapshot Range / Mesh. Скриптовые вызовы MaxScript/pymxs для анимации субобъектов и Snapshot требуют отдельной проверки в живом Max.
3. Не путай число кадров и число копий. В примере **320 кадров, 200 Mesh-копий**.
4. Проверяй результат через `result.json`, `scene.json` и `viewport.png`; не утверждай успех только по отправленному `command.json`.
5. Не удаляй существующую сцену без согласия пользователя. Для опытов создавай объекты с отдельным префиксом имени.
6. Метод подходит для пергол, ламелей, скамеек, ограждений, стен, мебели и скульптурных структур. Требования к соединениям, толщине и изготовлению решаются отдельно.

## Отличие от процедурного скрипта `000035`

Скрипт `000035` создаёт 73 профиля по математическим формулам с параметром `u`, `sin` и плавными переходами. Он **не использует** Path Constraint, Auto Key или Snapshot. Оба подхода могут дать родственные пространственные конструкции, но механизм создания принципиально различен.

## Статус проверки

Последовательность подтверждена авторскими скриншотами. Автоматизация именно этого штатного метода через Python/pymxs пока не испытана. Тест удалённого создания чайника подтверждает работу транспортного контура MaxBridge, но не доказывает автоматизацию Snapshot.
