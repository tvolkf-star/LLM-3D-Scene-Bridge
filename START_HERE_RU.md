# TASY MaxBridge 0.6.1 PORTABLE

## Установка и запуск

1. **[Скачайте полный комплект](https://github.com/tvolkf-star/LLM-3D-Scene-Bridge/releases/download/v0.6.1-portable/TASY_MaxBridge_v0.6.1_PORTABLE_COMPLETE.zip)** и распакуйте архив в отдельную папку.
2. Запустите **Autodesk 3ds Max 2024**. Выберите **Scripting → Run Script** и откройте `TASY_MaxBridge_061_PORTABLE.py`. Мост сам создаст рядом необходимые рабочие файлы и каталоги.
3. **Настройте синхронизацию этой папки через Google Drive для компьютера.** Папка должна оставаться доступной локально и синхронизироваться в обе стороны.
4. **Предоставьте ChatGPT доступ к папке Google Drive.** Передайте ему документацию проекта и попросите изучить примеры и протокол обмена.
5. **Поставьте задачу на моделирование.** ChatGPT сможет передавать команды мосту и получать результаты, если доступ к файлам и синхронизация настроены.

Готово. Можно работать.

## Возможные ошибки и способы обхода

### Мост не запустился

Убедитесь, что скрипт запущен **изнутри 3ds Max 2024** через **Scripting → Run Script**, а не двойным щелчком в Windows. Проверьте Python Listener: должны появиться `TASY MaxBridge 0.6.1 PORTABLE running` и путь `ROOT:`. Проверьте права записи в папку.

### Файлы не появились

Сверьте путь `ROOT:` с папкой, из которой запущен скрипт. Рабочие файлы создаются **рядом со скриптом**, а не обязательно в каталоге проекта Max. Часть файлов появляется при старте, часть после выполнения команд.

### ChatGPT не видит папку или не может записать команду

Проверьте доступ подключённого Google Drive, права записи и наличие локальной синхронизации. Папка может находиться в разделе **«Папки с компьютера»**, её необязательно переносить в «Мой диск».

Если чтение работает, но создание файла не удалось, проблема может быть в способе записи конкретного подключения. Проверенный технический обходной маршрут: создать командный файл в доступной папке Drive, скопировать его в рабочую папку моста с указанием её `folder ID`, затем обновлять существующий `command.json` на месте. Подробности: [INSTALL_RU.md](docs/INSTALL_RU.md).

### Команда не выполняется

Проверьте наличие `command.json` в папке `ROOT`, корректность JSON и **новый уникальный `id`** для каждой команды. Мост не повторяет уже обработанный ID.

### ChatGPT утверждает, что команда выполнена, но результата нет

Проверяйте `result.json`: его `command_id` должен совпадать с отправленным ID. Сверяйте `status` и `scene.json`. Без этого нельзя считать выполнение подтверждённым.

### Объект есть, но снимка viewport нет

Сохранение `viewport.png` выполняется по возможности. Отсутствие снимка само по себе не означает, что моделирование не сработало. Проверяйте объект непосредственно в 3ds Max и поле `viewport_saved` в результате.

### Ошибка в исполняемом Python

Читайте `error` и `traceback` в `result.json`. После исправления отправьте новую команду с **новым ID**.

### Два экземпляра мешают друг другу

Не запускайте два моста, работающих с одним `command.json`. Для второго экземпляра создайте отдельную папку.

### Пример неожиданно очистил сцену

**Сохраняйте работу перед запуском примеров.** Исходный скрипт перголы `MAF035_Pergola.py` содержит `resetMaxFile(noPrompt)` и сбрасывает сцену без предупреждения. Используйте пустую тестовую сцену.

### Важное ограничение безопасности

Команда `execute_python` запускает произвольный Python-код с правами процесса 3ds Max. Предоставляйте доступ к рабочей папке только доверенным участникам.
