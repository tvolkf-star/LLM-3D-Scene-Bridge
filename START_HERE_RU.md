# НАЧАТЬ ЗДЕСЬ | TASY MaxBridge 0.6.1 PORTABLE

**Это инструкция для человека, скачавшего полный ZIP с GitHub Release.** Рабочий мост и демонстрационные сцены запускаются в Autodesk 3ds Max 2024. Картинки PNG можно открыть любым просмотрщиком изображений, но это **не файлы сцен**.

## 1. Скачать и распаковать

[Скачать полный архив релиза](https://github.com/tvolkf-star/LLM-3D-Scene-Bridge/releases/download/v0.6.1-portable/TASY_MaxBridge_v0.6.1_PORTABLE_COMPLETE.zip).

Распакуйте ZIP целиком в удобную папку. Не запускайте Python непосредственно из ZIP. Сохраните структуру каталогов `examples/`, `assets/`, `docs/`.

## 2. Посмотреть картинки без 3ds Max

- `assets/margarita_archviz.png` — генеративная архитектурная визуализация на основе viewport.
- `assets/margarita_viewport.png` — снимок сцены в 3ds Max.

В репозитории есть дополнительные [изображения табуретки и перголы](media/), но **не следует предполагать, что они все включены в текущий ZIP**. Их можно посмотреть непосредственно на GitHub.

## 3. Запустить мост

1. Создайте **отдельную пустую папку с правами записи**, например `D:\MyMaxBridge`. Не используйте папку существующего рабочего моста.
2. Скопируйте туда `TASY_MaxBridge_061_PORTABLE.py` из распакованного комплекта.
3. Запустите **Autodesk 3ds Max 2024**.
4. Откройте **Scripting → Run Script** и выберите `TASY_MaxBridge_061_PORTABLE.py`.
5. В Python Listener проверьте строку `TASY MaxBridge 0.6.1 PORTABLE running` и путь `ROOT:`.
6. В рабочей папке появятся служебные файлы и каталог `library/`.

Сам по себе мост **не подключает ChatGPT**. Для удалённой работы нужна синхронизация рабочей папки, например через Google Drive для компьютера, и доступ управляющей стороны к файлам.

## 4. Проверить мост без моделирования

В рабочей папке создайте файл `command.json`:

```json
{"id":"test-ping-001","action":"ping"}
```

Дождитесь `result.json`. Проверьте совпадение `command_id`, `status: ok` и ответ `pong`.

**Каждая новая команда должна иметь новый `id`.** Если команда не исполнилась, проверяйте путь `ROOT`, корректность JSON и синхронизацию.

## 5. Создать тестовый объект через мост

Замените содержимое `command.json`:

```json
{"id":"test-teapot-002","action":"execute_python","code":"o=rt.Teapot(radius=250); o.name='Bridge_Test_Teapot'; rt.select(o); rt.execute('max tool zoomextents all')"}
```

Проверьте объект в 3ds Max, а также `result.json` и `scene.json`. Файл `viewport.png` появляется, если захват активного окна удался.

## 6. Запустить готовые примеры без моста

**Примеры Python запускаются непосредственно внутри 3ds Max, не двойным щелчком в Windows и не обычным системным Python.**

Сначала сохраните текущую работу и откройте отдельную пустую сцену.

- **«Маргарита»:** `examples/margarita/MARGARITA_v4_FULL_SOURCE.py`. В Max: **Scripting → Run Script**. Полная версия проходила практическую проверку; компактная `MARGARITA_v4_12KB.py` проверена на синтаксис, но отдельно в Max не испытывалась.
- **Пергола:** `examples/pergola/MAF035_Pergola.py`. В Max: **Scripting → Run Script**. **ОПАСНО ДЛЯ НЕСОХРАНЁННОЙ СЦЕНЫ: скрипт вызывает `resetMaxFile(noPrompt)` и очищает сцену без запроса.**
- **Табуретки:** каталог `examples/stools/`. Читайте скрипт и [пояснение](examples/stools/README.md) перед запуском. Индивидуальная проверка каждого файла в Max не заявляется.

Файл `examples/pergola/command_000035.json` — исходная команда **для моста**, а не Python-скрипт для пункта Run Script. Для самостоятельного запуска используйте соответствующий `.py`.

## 7. Как посмотреть и сохранить результат

- В 3ds Max используйте viewport, Scene Explorer и Modify Panel, чтобы проверить созданные редактируемые объекты.
- Сохраните сцену обычным способом через **File → Save As** в собственный `.max`.
- При работе через мост изучайте `result.json` (выполнение), `scene.json` (объекты и параметры) и `viewport.png` (изображение, если сохранено).
- `assets/*.png` в комплекте — **иллюстрации ранее полученных результатов**, они не открываются как редактируемые сцены.
